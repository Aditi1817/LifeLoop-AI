# 🌍 LifeLoop AI - Carbon Footprint Awareness Platform

## 🏆 Hackathon Project

LifeLoop AI is a complete, production-ready sustainability platform that helps individuals understand, track, and reduce their carbon footprint through AI-powered recommendations and gamification.

## ✨ Features

### 🔐 Authentication System
- Secure user registration and login
- Password hashing with bcrypt
- JWT-based session management
- User profiles and statistics

### 📊 Carbon Assessment
- Interactive carbon footprint calculator
- Real-time results with beautiful visualizations
- Category breakdown (Transport, Food, Energy, Shopping)
- Eco Score and trees needed metrics

### 🤖 AI Sustainability Coach
- Google Gemini API integration
- Personalized recommendations
- Impact measurements and savings estimates
- Difficulty ratings for each action

### 🎯 Gamification
- XP system with level progression
- Weekly eco missions
- Achievement system
- Progress tracking

### 📈 Progress Dashboard
- Visual trend analysis
- Historical data tracking
- Carbon reduction monitoring
- Interactive charts

### 🍽️ Food Waste Assistant
- Ingredient management
- Recipe suggestions
- Storage tips
- Waste reduction strategies

### ✨ Unique Features
- Glass morphism UI design
- Smooth animations
- Toast notifications
- Daily sustainability tips
- Mobile-responsive design

## 🛠️ Technology Stack

- **Frontend**: Streamlit
- **Backend**: Python
- **AI**: Google Gemini API
- **Charts**: Plotly
- **Authentication**: bcrypt, JWT
- **Database**: JSON file storage
- **Security**: Password hashing, input validation
